# Phase 0: Project Initialization & Setup

1. Initialize Vite project with React and TypeScript for a robust, type-safe development environment.
2. Set up the project folder structure including `components`, `hooks`, `db`, and `styles` directories.
3. Configure global CSS variables for the "Soft Dark" theme, entry-specific colors, and set JetBrains Mono as the global font for all elements.
4. Implement a basic responsive layout shell with a fixed Header and a placeholder for the Floating Action Button (FAB).
5. Install and configure Lucide-react for high-aesthetic icons as per the design philosophy.
