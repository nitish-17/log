# Phase 3: Timeline & Duration Logic

1. Implement the reverse-chronological rendering of log entries on the main dashboard.
2. Design and code the vertical dotted line connector that runs behind/between timestamps without overlapping text.
3. Create the `DurationDisplay` component to calculate and show the time gap between entries in `x h y m` format.
4. Apply logic to hide duration text and minimize card gaps for entries with a time difference of less than 60 seconds.
5. Ensure the timeline and duration labels automatically recalculate and re-animate upon any entry deletion or update.
